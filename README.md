# minipmo

A personal PMO tool: create a project in under 10 minutes and see, at any
point, where it stands, what is at risk and what needs a decision.

- **Plan:** Phase → Main activity → Sub-activity, on a Gantt timeline and a
  Kanban board that share the same records.
- **Progress:** duration-based weightage (editable), planned vs actual % rolled
  up to the project, S-curve and rule-based RAG.
- **Control:** baseline, dependencies, milestones and a RAID log.
- **Report:** portfolio dashboard and a one-click weekly status report
  (PDF and PowerPoint).

No server and no logins. Data lives in the browser (IndexedDB) and is backed up
as JSON to a separate private GitHub repo.

Requirements and decisions: [docs/PRD.md](docs/PRD.md).
